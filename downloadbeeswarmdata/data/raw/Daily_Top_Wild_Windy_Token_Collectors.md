# Daily Top Wild Windy Token Collectors

The **Daily Top Wild Windy Token Collectors** is one of the 64 [leaderboards](/wiki/Leaderboards "Leaderboards") in the game, and is only viewable via the Global Leaderboards menu in the [System Page](/wiki/System_Page "System Page"). This leaderboard shows how many tokens dropped by [Wild Windy Bee](/wiki/Wild_Windy_Bee "Wild Windy Bee") players have collected on that day. It shows 10 leaderboard positions at a time. The player can scroll down the leaderboard to see more players, all the way to the 100th place. It resets every day at 12:00 AM CST.
