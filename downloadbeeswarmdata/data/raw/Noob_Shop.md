# Noob Shop

## Noob Shop

[ ![Shop1New](https://static.wikia.nocookie.net/bee-swarm-simulator/images/6/62/Shop1New.png/revision/latest/scale-to-width-down/268?cb=20240122135114) ](https://static.wikia.nocookie.net/bee-swarm-simulator/images/6/62/Shop1New.png/revision/latest?cb=20240122135114 "Shop1New")

### Location

Starter Zone

The **Noob Shop** is a [shop](/wiki/Category:Shops "Category:Shops") run by [Noob Bear](/wiki/Noob_Bear "Noob Bear"). This shop sells four [bags](/wiki/Bags "Bags"), five [tools](/wiki/Tools "Tools"), one [hat](/wiki/Category:Hats "Category:Hats"), one pair of [boots](/wiki/Category:Boots "Category:Boots"), and one [belt](/wiki/Category:Belts "Category:Belts"). It is located right next to the [Dandelion Field](/wiki/Dandelion_Field "Dandelion Field"), and below the entrance of the [Star Hall](/wiki/Star_Hall "Star Hall"). It is the first shop, other than the [Ticket Tent](/wiki/Ticket_Tent "Ticket Tent"), players have access to. 

[Onett](/wiki/Onett_\(Developer\) "Onett \(Developer\)") has not yet revealed the official name of this shop; it has been named "Noob Shop" by the players because the bear inside is labeled "Noob Bear". However, when [Mother Bear](/wiki/Mother_Bear "Mother Bear") talks about [amulets](/wiki/Amulet "Amulet") with the player, she calls the shop, "Noob Bear's Shop." 

Outside of the shop, there is a [Honey Dispenser](/wiki/Honey_Dispenser "Honey Dispenser"), which can only be used by members of the [Bee Swarm Simulator Club](https://www.roblox.com/groups/3982592/Bee-Swarm-Simulator-Club#!/about). 

Behind the Honey Dispenser is a hidden [obstacle course](/wiki/Obstacle_Courses#Lava_Obby "Obstacle Courses"). There is a ![Royal Jelly](https://static.wikia.nocookie.net/bee-swarm-simulator/images/9/9f/Royal_Jelly.png/revision/latest/scale-to-width-down/25?cb=20230404020655)[Royal Jelly](/wiki/Royal_Jelly "Royal Jelly") token at the end of it, located inside the Noob Shop. This obstacle course also has the [Demon Mask](/wiki/Demon_Mask "Demon Mask") shop. During the [Egg Hunt 2019](/wiki/Egg_Hunt_2019 "Egg Hunt 2019") event, a ![Plastic Egg](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)[Plastic Egg](/wiki/Plastic_Egg "Plastic Egg") token was added to this course as a part of [Brown Bear's Egg Hunt 2019 Quest](/wiki/Brown_Bear#Egg_Hunt_Quest_2019 "Brown Bear"); but this token was removed after the event and replaced with a token that gives ![Ticket](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)3 [Tickets](/wiki/Ticket "Ticket"). 

[Spotted Chicks](/wiki/Chicks#Spotted_Chick "Chicks") could have spawned here during the [2020 Egg Hunt Event](/wiki/Egg_Hunt_2020 "Egg Hunt 2020"), however this was removed.

## Trivia[[](https://auth.fandom.com/signin?redirect=https%3A%2F%2Fbee-swarm-simulator.fandom.com%2Fwiki%2FNoob_Shop%3Fveaction%3Dedit%26section%3D4&uselang=en&metadata=article-registration-edit-article-section "Sign in to edit")]

  * After the [2018-05-12 update](/wiki/Updates#2018-05-12 "Updates"), a green cog appeared on top of this shop. This is a hint for the [code](/wiki/Codes "Codes") "cog". 
    * On top of this cog, there is a ![Robo Pass](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)[Robo Pass](/wiki/Robo_Pass "Robo Pass") token.
  * Out of the three shops that have a shop bear, this is the only one that doesn't sell a [Gliding Tool](/wiki/Category:Gliding_Tools "Category:Gliding Tools").
  * The [Helmet](/wiki/Helmet "Helmet") is the most expensive item in the Noob Shop.
  * This is the only shop that has automatically equipped items, which are the [Scooper](/wiki/Scooper "Scooper") and the [Pouch](/wiki/Pouch "Pouch").
