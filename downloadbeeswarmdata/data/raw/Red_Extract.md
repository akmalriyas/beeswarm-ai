# Red Extract

Red Extract

[![Red Extract](https://static.wikia.nocookie.net/bee-swarm-simulator/images/b/b9/Red_Extract.png/revision/latest?cb=20230404020836)](https://static.wikia.nocookie.net/bee-swarm-simulator/images/b/b9/Red_Extract.png/revision/latest?cb=20230404020836)

_"Grants x1.25 Red Pollen for 10 minutes."_

COOLDOWN

1 second

A **Red Extract** is an [inventory item](/wiki/Category:Inventory "Category:Inventory") that was added in the [2018-11-25 update](/wiki/Updates#2018-11-25 "Updates"). The purpose of it is to use it as a material to craft [accessories](/wiki/Category:Accessories "Category:Accessories"), or for a 10-minute boost that grants x1.25 [Red Pollen](/wiki/System_Page#Red_Pollen "System Page"). The [buff](/wiki/Buffs_%26_Debuffs#From_Items "Buffs & Debuffs") cannot stack and will only reset its timer if you used a **Red Extract** when there is another one active. Using a ![Purple Potion](https://static.wikia.nocookie.net/bee-swarm-simulator/images/9/9c/Purple_Potion.png/revision/latest/scale-to-width-down/25?cb=20230404023738)[Purple Potion](/wiki/Purple_Potion "Purple Potion") or ![Super Smoothie](https://static.wikia.nocookie.net/bee-swarm-simulator/images/5/5f/Super_Smoothie.png/revision/latest/scale-to-width-down/25?cb=20230404023801)[Super Smoothie](/wiki/Super_Smoothie "Super Smoothie") will override the buff.
