# Tools

**Tools** are items that can gather [pollen](/wiki/Pollen "Pollen"). Some tools have special abilities that help assist in gathering pollen, while some collect better from certain colored [flowers](/wiki/Flowers "Flowers"), which include white, red, and blue. All tools can be boosted through the [Tool Pollen](/wiki/System_Page#Tool_Pollen "System Page") stat. The newest tool in the game was the [Sticker-Seeker](/wiki/Sticker-Seeker "Sticker-Seeker"). There are currently twenty tools in the game. 

Every player starts out with the [Scooper](/wiki/Scooper "Scooper"). Better tools can be bought from different [shops](/wiki/Category:Shops "Category:Shops"). The [Noob Shop](/wiki/Noob_Shop "Noob Shop") sells the cheapest tools, ranging from 0 - 14 thousand [honey](/wiki/Honey "Honey"). The [Pro Shop](/wiki/Pro_Shop "Pro Shop") follows with tools ranging from 40 thousand - 1.5 million honey, while the [Red HQ](/wiki/Red_HQ "Red HQ") and [Blue HQ](/wiki/Blue_HQ "Blue HQ") both have 2 tools each that can range from 3.5 million honey - 2.5 trillion honey. The [Mountain Top Shop](/wiki/Mountain_Top_Shop "Mountain Top Shop") has the fourth most expensive tools, with prices that range from 20 million - 150 million honey. The [Petal Shop](/wiki/Petal_Shop "Petal Shop") has the third most expensive tool at 1.5 billion honey. Currently, the most expensive tool in the game is the [Gummyballer](/wiki/Gummyballer "Gummyballer"), which can be bought for 10 trillion honey and other various [crafting materials](/wiki/Crafting "Crafting") in the [Gummy Bear's Lair](/wiki/Gummy_Bear%27s_Lair "Gummy Bear's Lair"). Unlike any other tool, the Gummyballer can directly take [goo](/wiki/Goo "Goo") off a field. 

The player can auto-click their pollen collector by holding down the mouse button on a computer. On a mobile device, holding on an open part of the screen does the same. Using [Glue](/wiki/Glue "Glue") gives a 10-minute boost that grants x1.25 Tool Pollen and bees. Using a [Purple Potion](/wiki/Purple_Potion "Purple Potion") can also give x1.25 [Capacity](/wiki/System_Page#Capacity_Multiplier "System Page"), x1.25 [Convert Rate At Hive](/wiki/System_Page#Convert_Rate_At_Hive "System Page"), x1.5 [Red Pollen](/wiki/System_Page#Red_Pollen "System Page"), x1.5 [Blue Pollen](/wiki/System_Page#Blue_Pollen "System Page"), x1.3 [Bee Gather Pollen](/wiki/System_Page#Pollen_From_Bees "System Page"), and x1.3 [Tool Pollen](/wiki/System_Page#Tool_Pollen "System Page") for 15 minutes. There is also a glitch for computer in which holding down click then Ctrl + Esc or Alt + tab automatically uses your tool, but clicking the screen removes it. This can also be achieved by moving the mouse outside of the boundaries in windowed mode, but it can only be done on the launcher version of the app.
