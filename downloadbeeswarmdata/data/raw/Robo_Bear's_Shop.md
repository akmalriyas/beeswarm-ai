# Robo Bear's Shop

## Robo Bear's Shop

[ ![RoboBear'sShop](https://static.wikia.nocookie.net/bee-swarm-simulator/images/9/99/RoboBear%27sShop.png/revision/latest/scale-to-width-down/268?cb=20260204020853) ](https://static.wikia.nocookie.net/bee-swarm-simulator/images/9/99/RoboBear%27sShop.png/revision/latest?cb=20260204020853 "RoboBear'sShop")

### Location

Seen above Robo Bear.

  
**Robo Bear's Shop** is a [shop](https://bee-swarm-simulator.fandom.com/wiki/Category:Shops) run by [Robo Bear](/wiki/Robo_Bear "Robo Bear") located right of the [Red HQ](/wiki/Red_HQ "Red HQ"), next to the [Rose Field](/wiki/Rose_Field "Rose Field"). This shop sells all of the [drives](/wiki/Drives "Drives"), and [Digital Bee](/wiki/Digital_Bee "Digital Bee"). It was added alongside the rest of Robo Bear's area in the [2022-12-26](/wiki/Updates "Updates") update. 

Robo Bear's Shop is not the official name of the shop; it is only called this (assumably) because the owner of the shop is Robo Bear. 

The formula for the price of each colored drive in honey is 

P ( n ) = 250,000 n 2 {\displaystyle P(n) = 250{,}000n^{2}} ![{\\displaystyle P\(n\)=250{,}000n^{2}}](https://services.fandom.com/mathoid-facade/v1/media/math/render/svg/24366f05093a25fba6579ad38dee4f303342ec41)

where _n_ represents the _n_ th drive of that type to purchase (1st is 250,000, 2nd is 1,000,000, 3rd is 2,250,000, etc). The price for [Glitched Drives](/wiki/Glitched_Drive "Glitched Drive") begins at _n + 1_.
