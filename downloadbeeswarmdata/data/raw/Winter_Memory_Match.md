# Winter Memory Match

![Digital Bee](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D) | **This piece of content contains information obtained through datamining.** Due to the nature of the information, details may be inaccurate or outdated.

**Memory Match** is a match-style minigame located in various places throughout the map. The goal is to match as many pairs as possible to win [items](/wiki/Items "Items"). There are four (five during Beesmas) of these machines that can be used. Each machine costs a varying amount of [honey](/wiki/Honey "Honey"). (See below.)

When activated, a screen will pop up with a board of size 4x4 or 4x5 grids. A player has a limited number of chances to match cards together. Matching a pair also costs a chance. They can gain more chances if they have the required certain ranks of [field badges](/wiki/Badges "Badges") to get it. 

Machines with rarer rewards require more honey and a higher badge rank for extra chances. They also have a longer cooldown between each activation. 

If at least one match is made, a message will appear in the chat:  Winner!, with the items matched and the amount listed below. 

If no matches are made, a message will appear in the chat:  Better luck next time!

## Winter Memory Match

[ ![Winter Memory Match](https://static.wikia.nocookie.net/bee-swarm-simulator/images/6/6c/Winter_Memory_Match.png/revision/latest/scale-to-width-down/268?cb=20210201042432) ](https://static.wikia.nocookie.net/bee-swarm-simulator/images/6/6c/Winter_Memory_Match.png/revision/latest?cb=20210201042432 "Winter Memory Match")

### Location

Near the [Pine Tree Forest](/wiki/Pine_Tree_Forest "Pine Tree Forest") and the [Sticker Stack](/wiki/Sticker_Stack "Sticker Stack")

### Cost

![Snowflake](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)100 [Snowflakes](/wiki/Snowflake "Snowflake")

### Cooldown

4 hours

### Size

4x5

The **Winter Memory Match** is a limited-time memory match added in the [Beesmas 2020 update](/wiki/Updates#2020-12-25 "Updates") and reintroduced in every Beesmas event since. It is located near the [Pine Tree Forest](/wiki/Pine_Tree_Forest "Pine Tree Forest") and the [Sticker Stack](/wiki/Sticker_Stack "Sticker Stack"). It costs ![Snowflake](data:image/gif;base64,R0lGODlhAQABAIABAAAAAP///yH5BAEAAAEALAAAAAABAAEAQAICTAEAOw%3D%3D)100 [Snowflakes](/wiki/Snowflake "Snowflake") to use and has a 4-hour cooldown. The player can only play it after completing [Spirit Bear's quest for that Beesmas](/wiki/Spirit_Bear#Beesmas_Quests "Spirit Bear").   
The size of the board is 4x5 cards. The base number of chances is 5, increasing by 1 for owning each of the badges listed below:   


  * [Pine Tree](/wiki/Pine_Tree_Forest "Pine Tree Forest") \- Master
  * [Stump](/wiki/Stump_Field "Stump Field") \- Master
  * [Coconut](/wiki/Coconut_Field "Coconut Field") \- Master



When a player attempts to use this without having completed Spirit Bear's Beesmas quest, the following message appears:  Looks like you need a membership of some sort to play Winter Memory Match...

## Trivia[[](https://auth.fandom.com/signin?redirect=https%3A%2F%2Fbee-swarm-simulator.fandom.com%2Fwiki%2FMemory_Match%3Fveaction%3Dedit%26section%3D11&uselang=en&metadata=article-registration-edit-article-section "Sign in to edit")]

  * The Extreme Memory Match is the biggest Memory Match machine in terms of the "computer" model size. It is also the most expensive machine in terms of honey.
  * If the player started a new memory match game while one was already active, the new game would not have started, but the player still had to pay the fee and wait for the cooldown. This is no longer possible because the player's movespeed is set to zero during a memory match game. 
    * The player can still move during the minigame by using the [Parachute](/wiki/Parachute "Parachute") or [Glider](/wiki/Glider "Glider").
  * The Winter Memory Match is the only machine that can only be accessed during an event and requires the completion of a quest to use, namely [Spirit Bear's quest for that Beesmas](/wiki/Spirit_Bear#Beesmas_Quests "Spirit Bear").
  * The Winter Memory Match had an unusual bug where if the player did not have enough snowflakes, trying to use the machine displayed the message: 



and Complete 1 Quest to You need 100 Snowflakes to play Winter Memory Match.

  * Assuming there are no duplicate pairs and the player is playing optimally, the chances of getting any prizes in a Memory Match for each board size is: 
    * For 4x4: about 37% for 3 chances, 46% for 4 chances, 54% for 5 chances, and 60% for 6 chances.
    * For 4x5: about 45% chance to reward the player if they receive 5 chances, 51% for 6 chances, 56% for 7 chances, and 61% for 8 chances.
