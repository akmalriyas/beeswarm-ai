Context: Bee Swarm Simulator - Brick

Datamined information: The formula for the cost of buying Bricks.
Date of datamined file: March 18th, 2026
_"Used for purchases during the Retro Challenge"_
The Brick is used as the main currency of the Retro Swarm Challenge. It is used to buy many utilities to fend off many waves of slimes and zombies during the challenge.
Ways to Obtain[]
* Farming in the Red, Blue, White, and Mixed Brick Field.
* Destroying Brick Blooms (Amount depends on the level).
* Slaying Slimes and Zombies (Amount depends on the level).
* 10 Bricks can be purchased for honey near the hives.
* 100 Bricks can be purchased for honey on the left side of the monster's spawn.
Cost of buying bricks[]
Let n be the number of bricks already bought. The cost of the next brick is equal to  Cost ( n ) = ⌊ n x ( n + 1 ) ⋅ y ( n + 1 ) ⌋ }(n)={\Big \lfloor }n^{{\text{x}}(n+1)}\cdot {\text{y}}(n+1){\Big \rfloor }}
* x ( n ) = { 1.2 if  n < 50 1.5 if  50 ≤ n < 100 1.75 if  100 ≤ n < 250 2 if  n ≥ 250 }(n)={\begin{cases}1.2&{\text{if }}n<50\\\1.5&{\text{if }}50\leq n<100\\\1.75&{\text{if }}100\leq n<250\\\2&{\text{if }}n\geq 250\end{cases}}}
* y ( n ) = { 10 if  n < 1000 20 if  1000 ≤ n < 2000 30 if  2000 ≤ n < 5000 40 if  n ≥ 5000 }(n)={\begin{cases}10&{\text{if }}n<1000\\\20&{\text{if }}1000\leq n<2000\\\30&{\text{if }}2000\leq n<5000\\\40&{\text{if }}n\geq 5000\end{cases}}}
As an example, if the player were to have 110 bricks already bought, then the cost of the next brick is equal to  Cost ( n ) = ⌊ 111 1.75 ⋅ 10 ⌋ ≈ }(n)={\Big \lfloor }111^{1.75}\cdot 10{\Big \rfloor }\approx }  37,363 Honey.
