Context: Bee Swarm Simulator - Debug Wax

Debug Wax
_"100% chance to greatly improve a Beequip."_
Debug Wax is an inventory item and a type of wax added in the 2024-07-17 update that can be used on a Beequip to boost its stats. Upon usage, it has a 100% chance of greatly improving the Beequip's stats. Debug Wax has an Upgrade Value of 4.
When applying Debug Wax to a bee's Beequip, a message pops up saying:
The Wax improved the Beequip!
Ways to Obtain[]
There are currently no ways to obtain a Debug Wax.
Outdated Methods[]
* As a reward for completing Bubble Bee Man's quest "B.B.M's Naughty List" during the Winter Beesmas 2024 event.
* As a reward for completing Bubble Bee Man's quest "B.B.M's Naughty List" during the Summer Beesmas 2024 event.
Trivia[]
* This is the only wax which is unable to be crafted.
* This item functions almost the same as a Caustic Wax, the only difference being that it always succeeds.
* This item originally shared its icon with Caustic Wax before the 2024-12-25 update.
* This item originated from the Test Realm, being a risk-free way to upgrade Beequips, before officially being added to the game.
* This wax, Soft Wax, and Swirled Wax are the only waxes guaranteed to change a beequip's stats.
