# Ant Pass Dispenser

![Ant Pass Dispenser](https://static.wikia.nocookie.net/bee-swarm-simulator/images/2/24/Ant_Pass_Dispenser.png/revision/latest/scale-to-width-down/267?cb=20260217213635)

The Ant Pass Dispenser is a dispenser located behind the Ant Gate, next to the Free Ant Pass Dispenser. It allows players to obtain Ant Passes using Tickets, which are required to access the Ant Challenge.

## Information

### Stats
*   **Cost:** 10 Tickets
*   **Requirement:** Requires 20 Bees and must have fewer than 10 Ant Passes in inventory.
*   **Cooldown:** None

### Usage Details
The dispenser provides an Ant Pass for a cost of 10 Tickets. This pass is necessary to enter the Ant Challenge. Unlike the Free Ant Pass Dispenser, this machine has no cooldown and its price never increases. Players cannot use this dispenser if they already possess 10 or more Ant Passes.

## Trivia
*   This dispenser, along with the Robo Pass Dispenser and the Free Robo Pass Dispenser, is one of the few dispensers that does not have visible faucets; instead, it features a small compartment resembling a vending machine.
*   The Ant Pass Dispenser, Royal Jelly Dispenser, and Robo Pass Dispenser are among the limited set of dispensers that require Tickets for use.
