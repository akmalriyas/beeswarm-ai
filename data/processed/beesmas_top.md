# Beesmas Top

A **Beesmas Top** is a Level 4 Beequip, categorized as a seasonal item. It has an equip limit of three and requires no specific color. It can only be equipped to Common or Rare bees.

"Younger bees enjoy giving this traditional Beesmas toy a spin."

## Stats Overview

### Base Statistics (Non-Caustic)
| Stat | Value | Upgrade Range | Notes |
| :--- | :--- | :--- | :--- |
| **Critical Chance** | 100% | +5% to +10% | Intervals of +1%. Bias scales linearly. |
| **Ability Rate** | 100% | +5% to +10% | Intervals of +1%. Bias scales linearly. |
| **Energy** | 100% | -25% to -15% | Intervals of +1%. Bias scales linearly. |
| **Bee Attack** | 10% | N/A | Fixed value. |
| **Critical Power** | 100% | +2% to +5% | Intervals of +1%. Bias scales linearly. |

### Upgrade Potential Statistics (Non-Caustic)
The potential values vary based on the RNG bias, but general ranges and averages are provided below:

*   **Critical Chance:** Base range is +5% to +10%. Average value tends toward +6.2% to +8.78%.
*   **Ability Rate:** Base range is +5% to +10%. Average value tends toward +6.2% to +8.78%.
*   **Energy:** Base range is -25% to -15%. Upgrade potential ranges from +5% to +10%. Average values vary significantly (e.g., -22.52% base, +7.99% upgrade).
*   **Critical Power:** Base range is +2% to +5%. Upgrade potential ranges from +2% to +5%. Average value tends toward +3.12% to +4.3%.

### Caustic Statistics (Non-Caustic)
The Caustic version features different RNG biases and higher average values:

*   **Critical Chance:** Base range is +5% to +10%. Average value tends toward +6.74% to +8.26%.
*   **Ability Rate:** Base range is +5% to +10%. Average value tends toward +6.74% to +8.26%.
*   **Energy:** Base range is -25% to -15%. Upgrade potential ranges from +5% to +10%. Average values vary significantly (e.g., -22.01% base, +7.99% upgrade).
*   **Critical Power:** Base range is +2% to +5%. Upgrade potential ranges from +2% to +5%. Average value tends toward +1.4675% to +3.2258%.

***Note on RNG:*** *The values shown in the raw data may differ greatly from the real-world values, as there is no way to view a beequip's true potential in-game; players can only see potential rounded to the nearest 1 star (or 0.5 star in Dapper Bear's Shop).*

## Trivia
This is one of eight beequips that can grant negative stats. The other seven are Kazoo, Whistle, Toy Horn, Toy Drum, Pink Eraser, Demon Talisman, and Lump Of Coal.
