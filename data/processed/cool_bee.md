# Cool Bee

**Cool Bee** is a Rare Blue bee, known for its sarcastic demeanor and ability to boost pollen collection from blue flowers.

| Attribute | Value |
| :--- | :--- |
| **Rarity** | Rare |
| **Color** | Blue |
| **Energy** | 20 |
| **Speed** | 14 |
| **Attack** | 2 |

### Habitat & Preferences
*   **Likes:** Bamboo Field, Pine Tree Forest
*   **Dislikes:** Strawberry Field
*   **Favorite Treat:** Blueberries

### Stats and Bonuses
Cool Bee has a base pollen collection of **10** in **3 seconds**. This translates to approximately 3.33 per second.

| Stat | Value / Effect | Notes |
| :--- | :--- | :--- |
| **Pollen Collection Rate** | 10 Pollen / 3 Seconds | Base rate. |
| **Honey Production Rate** | 120 Honey / 4 Seconds | Base rate. |
| **Gather Speed Bonus** | +25% | Increases pollen collection speed. |
| **Convert Amount Bonus** | +40 | Increases the amount converted to honey/resources. |
| **Attack Bonus** | +1 Attack | Minor combat boost. |

#### Gifted Hive Bonus (x1.1 Blue Pollen)
When Cool Bee is gifted, its pollen collection from blue flowers receives a 1.1x multiplier.

### Abilities
*   **Blue Boost:** Grants x1.2 pollen from blue flowers for 15 seconds. This ability can stack up to 10 times.
