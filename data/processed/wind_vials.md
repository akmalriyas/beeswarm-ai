# Wind Vials

[![Cloud Vial](https://static.wikia.nocookie.net/bee-swarm-simulator/images/7/7f/Cloud_Vial.png/revision/latest?cb=20230404033120)](https://static.wikia.nocookie.net/bee-swarm-simulator/images/7/7f/Cloud_Vial.png/revision/latest?cb=20230404033120)

*"Summons a Cloud in the field you're standing in. Lasts for 3 minutes."*

**Cooldown:** 1 second
**Cap:** 10

The **Cloud Vial** is a consumable inventory item introduced in the 2019-09-28 update. When used, it spawns a cloud in the field where the player is standing.

### Mechanics and Usage

*   **Inventory Limit:** Players can hold a maximum of 10 Cloud Vials. Obtaining more than this limit will only be possible through specific rewards like quests or Sticker Stack bonuses.
*   **Cloud Effects:** The summoned cloud moves around the field and provides several benefits:
    *   It grants a **25% pollen boost** to the player standing underneath it. This boost increases to 50% if the player is a Gifted Bee with a Windy Bee.
    *   It causes flowers under the cloud and sprouts in the field to grow faster. If a sprout is present, the cloud connects to it via a straight blue line, and the growth speed applied to the sprout increases based on the required pollen amount.
    *   Using a Cloud Vial on a field containing a planter makes that planter grow 8% faster per cloud, up to a maximum of 20%.
*   **Field Limits:** Each field has a limit for the number of clouds it can contain (higher-tier fields have higher limits). If this limit is reached, using another Cloud Vial will display the message: "There are too many clouds in this field."
*   **Restrictions:**
    *   Cloud Vials cannot be used in Ant Fields; attempting to do so results in the message: "You can't make clouds in a challenge field."
    *   They also cannot be used in the Hub Field, which displays the message: "You can't make clouds in the Hub Field."

### Donations and Rewards

Donating a Cloud Vial to the Wind Shrine after having donated a Spirit Petal gives the player a chance to obtain a Windy Bee Egg, provided they do not already own a Windy Bee.

The following audio plays when a Cloud Vial is used: [Vialuse.ogg](https://bee-swarm-simulator.fandom.com/wiki/File:Vialuse.ogg)

## Ways to Obtain

*   A reward from certain Spirit Bear and Bee Bear quests.
*   As a common drop from Wild Windy Bees.
*   A rare reward from Extreme Memory Match.
*   Redeeming specific codes (e.g., "BeesBuzz123").
*   As a Stack Reward for adding certain stickers to the Sticker Stack:
    *   Yellow Umbrella rewards 1 Cloud Vial.
    *   Simple Cloud rewards 1 Cloud Vial.
    *   Grey Raining Cloud rewards 3 Cloud Vials.
    *   Tornado rewards 3 Cloud Vials.
    *   Blowing Leaf rewards 3 Cloud Vials.
*   Purchasing the Winter Winds Bundle in Bee Bear's Catalog grants 3 Cloud Vials and other items.

### Methods No Longer Possible (Historical)

The following methods for obtaining Cloud Vials are no longer available:

*   Completing Spirit Bear's Ornament Quest (rewarded 10 Cloud Vials).
*   Opening the Pearly Present (rewarded 30 Cloud Vials).
*   Purchasing specific packs in the Robux Shop (e.g., The Beginner's Bean Bundle, The Star Treat Special).
*   Redeeming certain old codes (e.g., Gumaden10T, "1MLikes").
*   As a reward from some Sun Bear quests.
*   Purchasing the Refreshing Bundle in Bee Bear's Catalog (rewarded 20 Cloud Vials).
*   Completing some of Bee Bear's older quests.

## Token Locations

Cloud Vial tokens can be found in the Windy Bee Gate, located to the right of the Wind Shrine.

## Trivia

*   Cloud Vials do not spawn Wild Windy Bees. Instead, if a Spirit Petal has not yet been donated, using the vial will summon clouds. To specifically summon a Wild Windy Bee, the player must donate items to the Wind Shrine.
*   Cloud Vials are one of the only items that can directly aid in growing sprouts.
*   Clouds, sprinklers, and bubbles are the sole methods for regenerating flowers without relying on natural regeneration cycles.
*   With sufficient jump power, it is possible to collect a Cloud Vial token past the Windy Bee Gate without needing 35 bees. This can be achieved by jumping from the roof of the Red HQ into the collection area.
