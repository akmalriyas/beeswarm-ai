# Cloud Vial

[![Cloud Vial](https://static.wikia.nocookie.net/bee-swarm-simulator/images/7/7f/Cloud_Vial.png/revision/latest?cb=20230404033120)](https://static.wikia.nocookie.net/bee-swarm-simulator/images/7/7f/Cloud_Vial.png/revision/latest?cb=20230404033120)

*"Summons a Cloud in the field you're standing in. Lasts for 3 minutes."*

**Stats:**
*   **Cooldown:** 1 second
*   **Cap:** 10

The **Cloud Vial** is a consumable inventory item, introduced in the 2019-09-28 update. When used, it spawns a cloud in the field where the player is standing.

### Mechanics and Effects

The player can hold a maximum of 10 Cloud Vials in their inventory. If more than 10 are obtained (unless through specific quest or reward mechanics), they will not be added to the inventory.

**Cloud Effects:**
*   The summoned cloud moves around the field.
*   If the player is under the cloud, it grants a **25% pollen boost**. This boosts to **50%** if the player has a Gifted Bee and a Windy Bee.
*   It accelerates the growth of flowers and sprouts in the field. If there are sprouts present, the cloud helps them grow by connecting to the sprout with a straight blue line; this growing speed increases based on the pollen amount required for the sprout.
*   Using it on a field containing a planter causes that planter to grow 8% faster per cloud, up to a maximum of 20%.

**Field Limitations:**
*   Each field has a limit on the number of clouds allowed; larger and higher-tier fields have a greater limit. If this limit is reached, using another Cloud Vial will display the message: "There are too many clouds in this field."
*   The item cannot be used in challenge fields (like the Ant Field), resulting in the message: "You can't make clouds in a challenge field."
*   It also cannot be used in the Hub Field, displaying the message: "You can't make clouds in the Hub Field."

**Wind Shrine Donation:**
Donating a Cloud Vial to the Wind Shrine after having donated a Spirit Petal gives the player a chance to obtain a Windy Bee Egg, provided they do not already own a Windy Bee.

The following audio plays when a Cloud Vial is used: [Vialuse.ogg](https://bee-swarm-simulator.fandom.com/wiki/File:Vialuse.ogg)

## Acquisition Methods

**Current Ways to Obtain:**
*   A reward from certain Spirit Bear and Bee Bear quests.
*   As a very common drop from Wild Windy Bees.
*   A rare reward from Extreme Memory Match.
*   Redeeming specific codes (e.g., "BeesBuzz123").
*   As a Stack Reward for adding certain stickers to the Sticker Stack:
    *   Yellow Umbrella rewards 1 Cloud Vial.
    *   Simple Cloud rewards 1 Cloud Vial.
    *   Grey Raining Cloud rewards 3 Cloud Vials.
    *   Tornado rewards 3 Cloud Vials.
    *   Blowing Leaf rewards 3 Cloud Vials.
*   Purchasing the Winter Winds Bundle in Bee Bear's Catalog, which grants 3 Cloud Vials and other items.

**Deprecated Methods (No longer possible):**
The following methods are no longer available:
*   Completing Spirit Bear's Ornament Quest for 10 Cloud Vials.
*   Opening a Pearly Present for 30 Cloud Vials.
*   Purchasing packs in the Robux Shop, such as the Beginner's Bean Bundle (5 Cloud Vials) or the Star Treat Special (10 Cloud Vials).
*   Redeeming specific codes (e.g., Gumaden10T, "1MLikes", ”ThnxCyasToyBox").
*   As a reward from some of Sun Bear's quests.
*   Purchasing the Refreshing Bundle in Bee Bear's Catalog for 20 Cloud Vials.
*   Completing certain Bee Bear quests.

## Token Location
Cloud Vial tokens can be found in the Windy Bee Gate, located to the right of the Wind Shrine.

## Trivia
*   Cloud Vials do not spawn Wild Windy Bees. Instead, if a Spirit Petal has not yet been donated, it will summon clouds. To summon a Wild Windy Bee, the player must donate items to the Wind Shrine.
*   Cloud Vials are the only item that can directly help grow sprouts.
*   Clouds, sprinklers, and bubbles are the sole methods for regenerating flowers without them naturally regrowing.
*   With sufficient jump power, it is possible to collect a Cloud Vial token past the Windy Bee Gate without 35 bees by jumping from the roof of the Red HQ into the area where the token is located.
