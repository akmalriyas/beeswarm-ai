# Memory Match Minigames

**Memory Match** is a match-style minigame found throughout the map. The objective is to match as many pairs of cards as possible to earn various in-game items. There are several types of machines available, each with unique costs, board sizes, and reward pools.

## Gameplay Mechanics

When activated, a screen pops up featuring a grid (4x4 or 4x5). Players have a limited number of chances to match cards. Matching a pair consumes one chance.

Players can increase their starting chances by owning specific field badges associated with the machine. Machines offering rarer rewards typically require higher honey costs and badge ranks, and they often feature longer cooldown periods between activations.

*   **Success:** If at least one match is made, a "Winner!" message appears in chat, listing the matched items and quantity.
*   **Failure:** If no matches are made, the message "Better luck next time!" appears.

## General Trivia and Notes

*   The Extreme Memory Match is the largest machine in terms of model size and is the most expensive in terms of honey cost.
*   If a player attempts to start a new memory match while one was active, they would still incur the fee and wait for cooldown. However, this is no longer possible as the player's movement speed is set to zero during an active minigame (though players can move using Parachute or Glider).
*   The Winter Memory Match is unique among these machines as it is only accessible during a specific event period and requires completing Spirit Bear's related quest.
*   **Optimal Play Chance Estimates:** Assuming no duplicate pairs and optimal play, the general chance of receiving any prizes in a Memory Match is:
    *   4x4 board (3 chances): ~37%
    *   4x4 board (4 chances): ~46%
    *   4x4 board (5 chances): ~54%
    *   4x4 board (6 chances): ~60%
    *   4x5 board (5 chances): ~45%
    *   4x5 board (6 chances): ~51%
    *   4x5 board (7 chances): ~56%
    *   4x5 board (8 chances): ~61%
