# Memory Match Minigames

**Memory Match** refers to a series of match-style minigames found throughout the map. The objective is to match as many pairs as possible to earn various in-game items. There are several variants, each with unique mechanics, costs, and rewards.

***

## General Gameplay Mechanics

When activated, a screen pops up featuring a grid of cards (either 4x4 or 4x5). Players have a limited number of chances to match pairs. Matching a pair consumes one chance.

Players can gain additional chances by owning specific field badges associated with the machine. Machines offering rarer rewards typically require higher honey costs, demand a higher badge rank for bonus chances, and feature longer cooldowns.

*   **Success:** If at least one match is made, the chat displays: `Winner!`, listing the matched items and quantity.
*   **Failure:** If no matches are made, the chat displays: `Better luck next time!`

## Trivia and Mechanics

*   **Size & Cost:** The Extreme Memory Match is the largest board (4x5) and the most expensive machine in terms of honey.
*   **Game Flow:** If a player attempts to start a new memory match while one is active, the game will not restart; however, the fee must still be paid, and the cooldown timer continues. Players can move during the minigame using the Parachute or Glider.
*   **Optimal Chances (Theoretical):** Assuming no duplicate pairs and optimal play:
    *   4x4 boards: ~37% chance for 3 chances, ~60% chance for 6 chances.
    *   4x5 boards: ~45% chance for 5 chances, ~61% chance for 8 chances.
