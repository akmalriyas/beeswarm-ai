# Basic Bee

**Basic Bee** is an ordinary, hard-working bee. It is usually the first bee discovered and hatched in the game.

| Attribute | Value |
| :--- | :--- |
| **Rarity** | Common |
| **Color** | Colorless |
| **Energy** | 20 |
| **Speed** | 14 |
| **Attack** | 1 |

***

### Acquisition and Preferences

Basic Bee can be hatched from a Basic Egg or a Star Egg. It can also be obtained through the currently unobtainable Basic Bee Jelly. Note that it cannot be acquired from normal Royal Jellies or Star Jellies.

*   **Favorite Treat:** Sunflower Seeds
*   **Likes:** Sunflower Field, Clover Field, Mountain Top Field
*   **Dislikes:** Spider Field

### Statistics and Abilities

Basic Bee has a base pollen collection rate of 10 in 4 seconds (2.5 per second). It can produce 80 honey in 4 seconds (20 per second).

| Statistic | Base Value | Gifted Hive Bonus |
| :--- | :--- | :--- |
| **Pollen Collection** | 10 / 4s | x1.2 Pollen |
| **Honey Production** | 80 / 4s | N/A |

**Abilities:** None.

### Trivia & Lore

*   Basic Bee is the only type of Common bee.
*   Due to its widespread appearance in the game and thumbnails, Basic Bee is widely considered the main mascot of Bee Swarm Simulator.
*   It is one of three bees (along with Tabby Bee and Vicious Bee) that has an official plushie on the Official Bee Swarm Simulator Website.
*   The statistics for most other bees are described relative to Basic Bee's stats; for example, a +20 collection stat means the bee collects 20 more pollen than Basic Bee.
*   Basic Bee and Brave Bee are the only bees without inherent abilities. However, their Gifted forms can still produce Inspire tokens, and specific Beequips grant them abilities like Focus or Melody. This distinction is referenced by Bee Bear during its "Ability Token Tidings" quest.
*   Along with Event Bees, Basic Bee is one of the few bee types that cannot be obtained from a normal royal jelly because it is Common.
*   The expired code "DontUseThisJelly" provided a Basic Bee Jelly variant capable of transforming any bee into a Basic Bee.
*   Basic Bee and Demo Bee share the same skin color pattern when not gifted, while they possess similar colors in different patterns compared to Honey Bee.
*   Basic Bee's gifted bonus was initially +20% Pollen but was later buffed to x1.2 Pollen after the 2019-04-05 update, allowing it to stack with other pollen multipliers.
*   An image of a winking Basic Bee face appears at the end of the White Tunnel, which may reference the current code "Wink" and an older 2018-06-02 update thumbnail.
*   Basic Bee is the only kind of bee to appear in every different version of the game's official thumbnail.
*   Onett (Developer) has favored Basic Bee, Tabby Bee, and Rascal Bee, as revealed through Onett's dialogue.
*   Its face appears on various UI elements, including the Treat menu icon, Ticket interface, and the Beequip case.
*   The chances of obtaining a Gifted Basic Bee from sunflower seeds is 1 in 12,000 (the same chance applies to Legendary Bees when fed their favorite treats).
*   The hatching probability for a Gifted Basic Bee from a Basic Egg is 0.348% (1 out of 287.35632184).
*   Basic Bee, Tadpole Bee, Tabby Bee, Lion Bee, Puppy Bee, and Bear Bee are the only bees that represent realistic animals in the game (though all characters are technically bees).
*   Only Basic Bee, Brave Bee, Honey Bee, Lion Bee, and Windy Bee are featured on a gate.
