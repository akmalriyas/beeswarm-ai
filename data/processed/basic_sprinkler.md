# Basic Sprinkler

![Basic Sprinkler](https://static.wikia.nocookie.net/bee-swarm-simulator/images/c/c5/Basic_Sprinkler.png/revision/latest?cb=20180911213311)

The **Basic Sprinkler** is the lowest tier sprinkler available for purchase in the Badge Bearer's Guild. It is comprised of an individual unit, meaning only one can be placed at a time; previous sprinklers are removed if a new one is installed.

## Stats and Requirements

| Attribute | Value |
| :--- | :--- |
| **Requirement** | 10 Cadet Badges |
| **Cost** | 1,111,111 Honey |
| **Radius** | 7 tiles |
| **Rate (Regeneration)** | 5 seconds |
| **Setup Time** | 6 seconds |
| **Power** | 7 |

## Description and Mechanics

When planted in the ground, the Basic Sprinkler causes nearby flowers to regrow faster.

### Audio Effects
*   **Placement:** When a sprinkler is placed in a field: [Sprinklerbuild audio](https://bee-swarm-simulator.fandom.com/wiki/File:Sprinklerbuild.ogg)
*   **Regeneration:** When the sprinkler regenerates flowers: [Sprinklerwater audio](https://bee-swarm-simulator.fandom.com/wiki/File:Sprinklerwater.ogg)

## Trivia
*   The Basic Sprinkler is currently the cheapest sprinkler in the game.
*   It takes the longest amount of time to setup among all sprinklers (6 seconds).
