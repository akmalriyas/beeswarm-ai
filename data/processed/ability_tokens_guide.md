# Ability Tokens Guide

Ability tokens are special resources generated by bees that can be collected to activate unique abilities and buffs for the player. Most bees spawn these tokens, with exceptions being ungifted Basic Bees and Brave Bees without Beequips. If a player does not collect a token within a certain time limit, it fades away. Tokens generated by other players' bees are client-sided and generally invisible or uncollectible to the current player (though this was different prior to the May 7th, 2018 update).

Some tokens originate from sources other than bees (e.g., honey tokens from flowers). Players can distinguish between bee-generated tokens (which sparkle with gold) and field-generated tokens (which do not sparkle).

## Token Mechanics

### Spawning Categories
Ability tokens are categorized based on the activity of the generating bee:
*   **Gather:** Tokens generated while bees are collecting pollen. Most Gather tokens boost or collect pollen.
*   **Battle:** Tokens generated while bees are targeting or attacking mobs. These typically inflict damage or debuffs.
*   **Idle:** Tokens generated when bees are not engaged in gathering, attacking, or converting.

Some tokens can fall into multiple categories.

### Token Generation Variables
When a bee pauses after movement (gathering, attacking, or turning), it attempts to spawn its ability tokens. Each token has three key variables:

1.  **Use Cooldown:** The time required after the token is spawned before the bee attempts to summon that specific token again.
2.  **Attempt Cooldown:** The minimum waiting period between consecutive spawning attempts for a given token type.
3.  **Attempt Success Rate:** The probability that an attempt to spawn the token succeeds.

When attempting to spawn, the bee checks all available tokens against their cooldowns. If clear, it attempts the spawn. Successful tokens are added to a pool and then randomly selected from that pool for spawning. Once spawned, the token begins its use cooldown.

The average time required for an ability token to spawn can be calculated using the formula:
$$\text{Time} = \text{Use Cooldown} + \text{Attempt Cooldown} \times {\frac {1}{\text{Attempt Success Rate}}}$$

### Stat Modifiers
Several stats influence how tokens behave or are generated:

*   **Bee Ability Rate:** This stat modifies the spawn rate by dividing the use and attempt cooldowns (by the Bee Ability Rate percentage) and multiplying the attempt success rate. A 200% ability rate, for example, halves both cooldowns and doubles the success rate.
*   **Ability Token Lifespan:** Extends how long uncollected tokens remain on the field before despawning. This can be boosted by various Beequips (e.g., Stubborn Bee, Cog Amulet) and stickers, with a maximum possible increase of 145%.
*   **Ability Duplication Chance:** The probability that an ability token spawns a duplicated variant. Duped tokens last for double the original lifespan, which is further increased by the Digital Bee's level (5% per level). This chance can be boosted by field corruption or specific Digital Bees/upgrades.
*   **Bee Movespeed:** While not directly tied to token mechanics, higher bee movespeed allows bees to make more attempts at creating tokens, thereby increasing the overall average spawn rate.
