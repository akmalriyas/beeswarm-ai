# Gifted Bucko Bee

This page details the information for the quest-giving NPC, Gifted Bucko Bee. For the worker bee version of this character, please see the [Bucko Bee](/wiki/Bucko_Bee).

**Overview**

| Attribute | Detail |
| :--- | :--- |
| **Species** | Bee NPC |
| **Location** | Blue HQ (Second Floor) |
| **Prerequisites** | Discovered 4 blue types of bees |

Gifted Bucko Bee is one of three permanent [Quest Bees](/wiki/Category:Quest_Bees), alongside [Gifted Riley Bee](/wiki/Gifted_Riley_Bee) and [Honey Bee (NPC)](/wiki/Honey_Bee_\(NPC\)). He is located on the second floor of the Blue HQ, situated between the Top Bucko Bee Helpers and the Daily Top Blue Collectors Leaderboards.

To begin receiving or completing his quests, players must first acquire a [Translator](/wiki/Translator), which is given by Science Bear three times.

**Milestone Rewards**
*   Completing 150 quests grants access to craft the [Hydroponic Planter](/wiki/Hydroponic_Planter).
*   Completing 250 quests grants access to craft the [Tide Popper](/wiki/Tide_Popper).

## Rewards

Rewards vary based on the number of quests completed. Every quest completion grants one [Blue Extract](/wiki/Blue_Extract) and [Honey](/wiki/Honey).

**Specific Quest Rewards:**
*   The "Petals" quest rewards a [Bloom Shaker](/wiki/Bloom_Shaker).

**Honey Amount Table**
The amount of honey received is based on this table, where $Q$ is the number of quests completed plus one ($Q = \text{Quests Completed} + 1$). Only the highest value in the table is taken.

| Quest Milestone | Honey Amount |
| :--- | :--- |
| Every 100th quest | $25,000,000 \times Q$ |
| Every 5th quest | $2,500,000 \times \lfloor Q^{0.95} \rfloor$ |
| All other quests | $1,000,000 \times \lfloor Q^{0.9} \rfloor$ |

**Standard Quest Rewards (Non-Milestone)**
If the quest is not a milestone:
1.  The game checks if the current quest's rank is divisible by 25; if true, the player receives a [Star Jelly](/wiki/Royal_Jelly#Star_Jelly).
2.  Otherwise, it checks if the rank is divisible by 5, rewarding an item from the table below (where $Q = \text{Quests Completed} + 1$).
3.  For any other quest, there is a 5% probability of receiving an item from this table.

| Item | Amount | Chance to be Picked |
| :--- | :--- | :--- |
| [Treat](/wiki/Treat) | $(1+\lfloor \sqrt{Q} \rfloor \times 25)$ | $\sim 23.175\%$ |
| [Royal Jelly](/wiki/Royal_Jelly) | $(1+\lfloor \sqrt{Q} \rfloor \times 5)$ | $\sim 17.381\%$ |
| [Gumdrops](/wiki/Gumdrops) | 25 | $\sim 11.587\%$ |
| [Blueberry](/wiki/Blueberry) | $(1+\lfloor Q^{0.25} \rfloor \times 10)$ | $\sim 11.587\%$ |
| [Ticket](/wiki/Ticket) | 5 | $\sim 11.587\%$ |
| [Moon Charm](/wiki/Moon_Charm) | 20 | $\sim 11.587\%$ |
| [Magic Bean](/wiki/Magic_Bean) | 3 | $\sim 11.587\%$ |
| [Moon Charm](/wiki/Moon_Charm) | 50 | $\sim 1.159\%$ |
| [Blue Extract](/wiki/Blue_Extract) | 10 | $\sim 0.116\%$ |
| [Oil](/wiki/Oil) | 10 | $\sim 0.116\%$ |

## Trivia
*   Since quests are chosen randomly, including the first one, the formula for the initial requirement of any quest is "X divided by (number of Gifted Bucko Bee quests completed + 1)".
*   Gifted Bucko Bee is one of three NPCs based on bees; the others are [Gifted Riley Bee](/wiki/Gifted_Riley_Bee) and [Honey Bee (NPC)](/wiki/Honey_Bee_\(NPC\)). This bee is unique in that he resides indoors, although Gifted Riley Bee also resided indoors previously.
*   In the 2020 dialogue for Bucko Bee's Snow Machine, he mentions defeating ten spiders, but the quest requirements actually require the player to defeat five spiders.
*   Gifted Bucko Bee enjoys playing with marbles, as evidenced by his [Present](/wiki/Present) dialogue where he remarks: "Can't wait to crack this open and roll those bad boys around."
