# Toy Horn

A **Toy Horn** is a Level 9 Beesmas Beequip with an equip limit of two. It has no color requirement and can only be equipped to Brave, Rage, Lion, Cobalt, or Crimson bees. The item description reads: "This tiny brass instrument can be heard from miles away."

## Stats & Potential

The Toy Horn's stats are randomized based on its base values and potential upgrades. All results are rounded to at most 4 decimal digits.

### Base Stats (Non-Caustic)
| Stat | Value | Notes |
| :--- | :--- | :--- |
| **Convert Amount** | 100% | Random value between +30 - +60 |
| **Ability Pollen** | 100% | Random value between +1% - +5% |
| **Energy** | 100% | Random value between -20% - -10% |
| **Ability Rate** | Variable | Random value between 5% - 90% |
| **Ability** | Melody | Always present |

### Upgrade Potential (Base)
*   **Convert Amount:** A random value between +30 and +60. Bias scales linearly.
*   **Bias:** A random value between +3 and +6 (Intervals of +1).
*   **Ability Pollen:** A random value between +1% and +5% (Intervals of +1%).
*   **Energy:** Randomly ranges from -20% to -10%.

### Hive Bonus Stats
| Stat | Value | Notes |
| :--- | :--- | :--- |
| **Convert Rate** | Variable | Exact value between 0.05% - 0.1% (Upgrades: +1%, Limit: 20) |
| **Bee Ability Pollen** | Variable | Exact value between 0.02% - 0.05% (Upgrades: +1%, Limit: 5) |

***Note on Potential:** The values shown may differ greatly from the real in-game potential, as players can only see a beequip's potential rounded to the nearest 1 ★ (or 0.5 ★ in Dapper Bear's Shop).*

## Acquisition Methods

### Current Ways
*   As a drop from Onett's Lid Art.
*   Purchasing the Feelin' Festive Robux pack grants one Toy Horn, along with other items.

### Outdated Ways
The following methods have been removed or changed:
*   As a drop from the Jubilant Gift Box.
*   As a drop from the Brass Gift Box.
*   As a reward for purchasing the Jolly Jumbo Pack.

*   Purchasing the Fanfare Bundle from Bee Bear’s Catalog.
