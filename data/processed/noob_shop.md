# Noob Shop

![Shop1New](https://static.wikia.nocookie.net/bee-swarm-simulator/images/6/62/Shop1New.png/revision/latest/scale-to-width-down/268?cb=20240122135114)

## Overview
The **Noob Shop** is a shop located in the Starter Zone, run by [Noob Bear](/wiki/Noob_Bear). It is one of the first shops players can access (along with the Ticket Tent), situated right next to the Dandelion Field and below the entrance of Star Hall.

While Onett has not provided an official name for this shop, it was named "Noob Shop" by players due to its proprietor, Noob Bear. However, Mother Bear refers to the location as "Noob Bear's Shop."

The shop sells four [Bags](/wiki/Bags), five [Tools](/wiki/Tools), one [Hat](/wiki/Category:Hats), one pair of [Boots](/wiki/Category:Boots), and one [Belt](/wiki/Category:Belts).

### Adjacent Features
Outside the Noob Shop is a [Honey Dispenser](/wiki/Honey_Dispenser) that can only be used by members of the Bee Swarm Simulator Club. Behind this dispenser lies a hidden [Obstacle Course](/wiki/Obstacle_Courses#Lava_Obby), which contains a token for [Royal Jelly](/wiki/Royal_Jelly). This obstacle course also features the Demon Mask shop.

During the Egg Hunt 2019 event, a Plastic Egg token was added to this course as part of Brown Bear's Egg Hunt 2019 Quest; however, it was later replaced with a token granting three [Tickets](/wiki/Ticket). Spotted Chicks could have also spawned here during the 2020 Egg Hunt Event, but this feature was removed.

When inside the shop, the audio track "Vendor" plays. This music is also heard in several other locations, including the Pro Shop, Mountain Top Shop, Badge Bearer's Guild, Blue HQ, Red HQ, Petal Shop, Hive Hub, and the Blue Maze.

## Trivia
*   Following the 2018-05-12 update, a green cog appeared on top of this shop. This served as a hint for the "cog" code. A Robo Pass token was also placed atop this cog.
*   Of the three shops that feature a shop bear, the Noob Shop is the only one that does not sell a Gliding Tool.
*   The Helmet is the most expensive item available in the Noob Shop.
*   This is the only shop that automatically equips items upon entry: the Scooper and the Pouch.
