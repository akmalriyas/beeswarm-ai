# Hive Slot

![Hive Slot](https://static.wikia.nocookie.net/bee-swarm-simulator/images/5/53/Hive_Slot.png/revision/latest/scale-to-width-down/268?cb=20200403235655)

### Description
A Hive Slot increases the capacity of your hive, allowing you to hatch an additional bee.

### Mechanics and Cost
By default, a standard hive contains 25 Hive Slots for bees. Players can purchase up to 25 additional slots at the Mountain Top Shop, bringing the maximum total capacity to 50 slots.

The cost of these extra slots increases sub-exponentially, starting from 3,000,000 Honey for the first slot. The cost caps off at 2,169,203,229,760 (approximately 2.17 trillion) Honey for the 25th extra slot.

The cost progression is defined by the following equation:
$$y=4^{\left(-8\sin \left(0.1x-1\right)+x+3.8\right)}$$

### Trivia
*   The maximum number of hive slots used to be 40, but it has since been increased to 50.
*   SDMittens was the first player to obtain fifty hive slots, which she purchased on April 22, 2019.
*   Originally, Onett planned to add five additional hive slots that would cost Robux, but this feature was canceled. This plan was also visible in the Test Realm for a period of time.
*   In the Test Realm, it was possible to purchase 75 hive slots for testing purposes, but this functionality was removed and never implemented in the main game.
