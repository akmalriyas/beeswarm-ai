# Fireflies

Fireflies are passive mobs that only appear during nighttime. Individually, they produce sparkles on the flowers they land on. When grouped together, they generate various items for the player.

## Mechanics and Spawning

As soon as nighttime begins, a group of eight fireflies will spawn above the Star Hall. These fireflies then fly to a random field. Possible fields include:
*   Spider Field
*   Bamboo Field
*   Strawberry Field
*   Pineapple Patch
*   Cactus Field
*   Rose Field

Once they reach the designated field, they land randomly in a circle, facing towards the center. While on the flower, fireflies spawn sparkles.

## Interaction and Drops

The player can chase a firefly by walking close to it, forcing it to fly up. A firefly will fly up if a player is within a three-flower radius. If a firefly is nudged away, the flower it was sitting on generates sparkles.

When all eight fireflies are successfully nudged away and fly up, a formation might appear in the middle of the group, potentially dropping one of the following items:

| Possible Drops | Rarity | Notes |
| :--- | :--- | :--- |
| Moon Charms | Common | Increments of 1, 5, or 10. |
| Glitter | Rare | |
| Star Jelly | Very Rare | (Drops as Royal Jelly) |
| Night Bell | Extremely Rare | |
| Star Treat | 1/1,000,000 | |
| Waxing Crescent Moon Sticker | Rare | |
| Glowing Smile Sticker | Extremely Rare | |
| Star Signs Sticker | Extremely Rare | |
| Cyan Star Sticker | Exceptionally Rare | |
| Shining Star Sticker | Exceptionally Rare | |

The fireflies will repeat this cycle in one field three times before targeting a new field. This process continues until daytime arrives. When the sun rises, they fly back above the Star Hall and eventually despawn.

## Trivia

*   A firefly's face model is identical to that of the Gummy Bee, but its color is black rather than cyan.
*   Fireflies are one of only a few passive mobs in the game (along with frogs, chicks, spotted chicks, bean bugs, and puffshrooms).
*   Fireflies were the first passive mob introduced to the game and are also the only passive mobs that spawn exclusively at night.
*   If a player uses a Night Bell while a group of fireflies is leaving, another group will replace them. In an unknown update, the original group may return instead of a new one spawning.
*   Despite consisting of eight fireflies, the Glowing Smile Sticker only depicts seven "fireflies."
