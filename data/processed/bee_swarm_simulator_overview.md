# Bee Swarm Simulator Overview

**Bee Swarm Simulator** is an online multiplayer game developed by Onett on Roblox. The core objective of the game is to hatch bees, build a swarm, collect pollen, and convert that pollen into honey.

The game was in development for approximately three months before its creation on March 21, 2018, and its public release on March 23, 2018.

---

## Gameplay Mechanics

New players begin with the Tutorial (an optional 36-page slideshow accessible via the top-right '?' button). Players must claim one of six available hives by pressing 'E' or clicking the blue button near their hive.

Upon starting, new players automatically receive a Basic Egg, a Pouch, and a Scooper. Using the Scooper, players collect pollen from various Fields. This collected pollen is stored in the player's bag and can be converted into honey while the player remains at their hive.

Honey serves as the primary currency used to purchase:
*   New Tools
*   Accessories
*   Eggs
*   Various other Items for progression

Players can also engage with Quests given by NPCs, which typically involve collecting pollen or defeating Mobs. More advanced objectives include gathering Ability Tokens and Goo.

## Private Servers

Private servers cost 150 Robux per month. Owners of private servers have access to the following administrative commands:

*   `/kick PlayerName`: Kicks the specified player (PlayerName must be their true Roblox username).
*   `/ban PlayerName`: Permanently bans the named player from the server until the server is closed or `/unban` is used.
*   `/unban PlayerName`: Removes a banned player from the ban list.

If a private server becomes inactive due to non-payment, all previously banned players will be automatically unbanned when the server reactivates.
