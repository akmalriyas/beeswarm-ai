# Gummy Cannon

The **Gummy Cannon** is a personal cannon used by Gummy Bear to fire gumdrops onto designated fields. It was introduced during the 2018-05-26 update and was later removed alongside Gummy Bear.

The cannon's color scheme matches that of goo, gumdrops, Gummy Bee, and Gummy Bear: it features a teal base and a pink barrel. It was originally found near Gummy Bear and Gummy Bee.

### Mechanics

When Gummy Bear launches the cannon, all players on the server receive a notification stating: "Sights Set on the [Field Name]!" Gumdrops are then scattered across the selected field until the field changes.

Starting in Beesmas 2020 and returning during subsequent Beesmas events, the cannon can be summoned by using the Gummy Beacon to summon a Gummy Siege, provided that Gummy Bear's Beesmas Quest has been completed. Each time gumdrops are scattered on a field, a corresponding gumdrop token appears in its place.

## Trivia

*   The Gummy Cannon is unique among cannons as it was not used for player transportation; its sole function is decorative and item launching. It is also the first and only cannon capable of launching items.
*   When the Gummy Cannon launches gumdrops, the falling animation matches the animation used when a player manually drops gumdrops onto a field.
*   The cannon's accuracy is imperfect. The launched gumdrops can miss their intended fields or splatter goo into nearby areas.
*   It is one of the few cannons that was removed from the game only to be returned later.
*   The cannon fires 5–7 gumdrops before it aims at other fields.
*   There used to be a dedicated gumdrop token behind the cannon. After the Gummy Invasion event concluded, this token was covered by a green path, making it harder to obtain, though it remained possible by moving along the edge of the path.
