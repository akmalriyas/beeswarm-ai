# Smooth Dice

[![Smooth Dice](https://static.wikia.nocookie.net/bee-swarm-simulator/images/c/c6/Smooth_Dice.png/revision/latest?cb=20230130020832)](https://static.wikia.nocookie.net/bee-swarm-simulator/images/c/c6/Smooth_Dice.png/revision/latest?cb=20230130020832)

> "Boosts 2 random fields for 200% pollen for 15 minutes."

**Cooldown:** 2 seconds

The **Smooth Dice** is an inventory item introduced in the 2021-12-26 update. When used, it boosts two random fields, each granting a 200% pollen field boost. If another dice boost is active when this item is used, it replaces the duration of the previous boost.

## Acquisition Methods (Current)

*   **Crafting:** Can be crafted using a Blender with the following ingredients:
    *   3 Field Dice
    *   3 Soft Waxes
    *   3 Whirligigs
    *   3 Oils
*   **Token Drops:**
    *   Found as a token on Dapper Bear's Shop.
    *   Found as a token on Hive Hub after completing parkour.
*   **Mob Drops:** Rare drop from Mantis and King Beetle.
*   **Planter Drops:**
    *   Petal Planters and Tacky Planters have a chance to drop Smooth Dice.
    *   Planters located in the Pumpkin Patch provide extra Smooth Dice drops.
*   **Harvest Bonus:** Received as a bonus drop when harvesting a planter in the Clover Field.
*   **Puffshroom Drops:** Rare drop from Puffshrooms (excluding common puffshrooms).
*   **Challenge Rewards:** Awarded by completing the Robo Bear Challenge and the Retro Swarm Challenge.
*   **Sticker Stack Reward:** Received as a stack reward for adding specific stickers:
    *   Orange Swirled Marble rewards 3 Smooth Dice.
    *   Blue and Green Marble rewards 3 Smooth Dice.
    *   Yellow Swirled Marble rewards 3 Smooth Dice.

## Acquisition Methods (Outdated)

The following methods are no longer available:

*   From a token inside the 2021 Beesmas Tree.
*   Purchasing the Charming Bundle in Bee Bear's Catalog for 3333 Snowflake.
*   As a reward from finishing a Robo Party.
*   For completing specific Bee Bear's Beesmas 2022 quests (3rd, 8th, 12th, and 15th).
*   As a reward from Winter Memory Match.
*   The Pastel Gift Box provided 4 Smooth Dice plus other items.
*   Using certain expired codes:
    *   `5Years` (Gave 5 smooth dice + other stuff).
    *   `boo swarm` (Gave 1 smooth dice + other stuff).
    *   `BoxWhoops` (Gave 1 smooth dice + other stuff).
*   Activating the target in the Sunflower Field using the Instant Converter dropped one Smooth Dice.

## Crafting Uses

The following items can be crafted using Smooth Dice:

| Quantity | Ingredients | Result |
| :---: | :--- | :--- |
| 3 | 3 Hard Waxes, 3 Oils, 1 Glue | Loaded Dice |

## Trivia

*   **Dice Rolling Notification:** If a player attempts to roll another dice while one is already rolling, the notification "You are already rolling a dice" will appear.
*   **Raw Ingredient Cost:** The raw ingredients required for Smooth Dice cost:
    *   270 Royal Jellies
    *   450 Sunflower Seeds
    *   300 Pineapples
    *   150 Blueberries
    *   150 Strawberries
    *   30 Honeysuckles
    *   6 Whirligigs
*   **Field Boost Stacking:** Smooth Dice and Loaded Dice are the only items capable of granting more than x1 stack of field boost.
