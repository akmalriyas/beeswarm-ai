# Elite Red Guard

![Elite Red Guard](https://static.wikia.nocookie.net/bee-swarm-simulator/images/5/56/Elite_Red_Guard.png/revision/latest?cb=20190403020221 "Elite Red Guard")

## Overview
The **Elite Red Guard** is a guard purchasable in the [Red HQ](/wiki/Red_HQ). It is equipped on the left shoulder and is reserved for dedicated Red Beekeepers.

### Description
"A Red Guard reserved for the most dedicated Red Beekeepers."

### Acquisition Cost
To craft the Elite Red Guard, players must use:
*   5,000,000 [Honey](/wiki/Honey)
*   3 [Red Extracts](/wiki/Red_Extract)
*   50 [Strawberries](/wiki/Strawberry)
*   5 [Royal Jelly](/wiki/Royal_Jelly)
*   5 [Stingers](/wiki/Stinger)

This guard is one of three available guards in the Red HQ, alongside the standard [Red Guard](/wiki/Red_Guard) and the [Riley Guard](/wiki/Riley_Guard).

## Stats
The Elite Red Guard provides the following bonuses:
*   +75,000 Capacity
*   +25% Red Pollen
*   +7% Defense
*   +5% Critical Chance
*   +1 Red Bee Attack
