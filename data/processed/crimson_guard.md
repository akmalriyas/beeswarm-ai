# Crimson Guard

![Crimsonguard](https://static.wikia.nocookie.net/bee-swarm-simulator/images/1/17/Crimson_Guard.png/revision/latest/scale-to-width-down/268?cb=20181128090650)

## Overview
The Crimson Guard is a high-tier red guard that can be crafted in the Badge Bearer's Guild. It is described as: "A guard bestowed with the heroic power of Crimson Bee - Defender of the Red Bees." When equipped on the left shoulder, it leaves a trail similar to Crimson Bee's trail.

## Stats and Bonuses
| Stat | Value |
| :--- | :--- |
| Capacity | +250,000 |
| Red Pollen | +50% |
| Red Bomb Pollen | +20% |
| Red Bee Attack | +3 |
| Defense | +10% |
| Critical Chance | +10% |

**Passive Ability: Focus Pulser**
Every 30th focus token releases a red pulse, which hops to each red bee, collecting pollen around them. The power of this pulse increases with each hop. Unlike standard ability tokens, this effect does not trigger a blue pulse, even if the player owns a Cobalt Bee or the Cobalt Guard.

## Crafting Information
The Crimson Guard can be crafted using the following ingredients:

*   **Honey:** 200,000,000
*   **Red Extracts:** 100
*   **Stingers:** 100
*   **Oil:** 50
*   **Glitter:** 25

## Trivia
*   The Crimson Guard is the only red guard that cannot be purchased in the Red HQ.
*   It is one of only two guards (the other being the Cobalt Guard) to possess a passive ability.
*   Its blue counterpart is the Cobalt Guard.
*   Along with the Cobalt Guard, this guard is one of only two in the game to leave a trail behind when the player moves.
