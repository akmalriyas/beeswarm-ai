# Demon Talisman

The **Demon Talisman** is a Level 13 Beequip with an equip limit of one. It requires a Red color and can only be equipped to a mutated Demon Bee. Its description reads: "An ornament trying hard to look conventionally evil."

## Stats Overview

| Stat | Base Value | Upgrade Range | Notes |
| :--- | :--- | :--- | :--- |
| **+Bee Attack%** | 100% | +50% - +70% (Random) | Biased towards higher values. |
| **+Gather Amount%** | 100% | +50% - +70% (Random) | Biased towards higher values. |
| **+Ability Pollen%** | 100% | +50% - +70% (Random) | Biased towards higher values. |
| **Gathering Flames Chance%** | Exact value: 10% - 50% | Random range provided in tables. | Base chance is fixed, upgrades are variable. |
| **+Super-Crit Chance%** | Exact value: 10% - 50% | +2% (Base) to +30% (Max) | Fixed base chance, upgradeable with Caustic Wax. |
| **-Movespeed%** | 100% | -40% - -30% (Random) | Reduces movement speed. |
| **-Energy%** | 100% | -80% - -70% (Random) | Reduces max bee energy. |

### Ability
*   **Ability:** Inferno
*   **Cost:** Caustic Points Only
*   **Base Value Range:** Exact value between 0.000125 and 0.001.

## Acquisition Methods

The Demon Talisman can be obtained in several ways:
*   Purchased from Dapper Bear's Beequip Shop.
*   Dropped by the Heat-Treated Planter and Pesticide Planter.
*   As an exceptionally rare reward from the Robo Bear Challenge.
