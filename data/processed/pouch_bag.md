# Pouch Bag

![Pouch](https://static.wikia.nocookie.net/bee-swarm-simulator/images/7/79/Pouch.png/revision/latest?cb=20190402214811 "Pouch")

### Description
"A small bag."

| Cost | Capacity |
| :--- | :--- |
| Free | 200 Pollen |

The **Pouch** is the starter bag that new players automatically receive at the beginning of the game, along with the Scooper and the starter tool. It can be equipped in the Noob Shop. Since it is the initial item given to the player, it does not have a purchase price.

### Stats
*   Capacity: +200 Pollen.

### Trivia
*   In early versions of the game, the Pouch stored 150 pollen. It was later buffed to 250 and then nerfed back to 200.
*   Along with the Jar, this is one of the few bags whose base capacity is less than its cost (when considering Honey).
*   The Pouch, the Scooper, and a Basic Egg are the only items players start with when joining the game for the very first time.
