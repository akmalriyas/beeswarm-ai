# Blue Port-O-Hive

![Blue Port-O-Hive](https://static.wikia.nocookie.net/bee-swarm-simulator/images/5/56/Blue_Port-O-Hive.png/revision/latest/scale-to-width-down/268?cb=20190405220756)

The **Blue Port-O-Hive** is a bag item introduced in the 2019-04-05 Update. It can be purchased exclusively at the Blue HQ.

### Description
"A Port-O-Hive dipped in shiny blue paint."

### Stats and Capacity
| Attribute | Value |
| :--- | :--- |
| **Capacity** | 400,000 Pollen |
| **Convert Rate** | +150% |
| **Blue Bee Convert Rate** | +10% |
| **Instant Blue Conversion** | +10% |
| **Blue Pollen Bonus** | +10% |

### Crafting Requirements
To craft the Blue Port-O-Hive, players must use:
*   12,500,000 Honey
*   2 Blue Extracts
*   2 Soft Waxes

### Trivia
*   The Blue Port-O-Hive is one of three improved Port-O-Hives, alongside the Red Port-O-Hive and the Porcelain Port-O-Hive.
*   It was among the last variants of the four Port-O-Hive types to be added to the game.
*   This item is the only bag purchasable in the Blue HQ.
*   Prior to the 2024-05-23 Update, this item did not require any material requirements for purchase.
*   During Beesmas 2021, a reference was made by Bee Bear regarding "Blue Backpackers" (players equipped with the Blue Port-O-Hive), referencing a running stereotype within the BSS community. The associated Cool Backpack Sticker is also considered part of this reference.
