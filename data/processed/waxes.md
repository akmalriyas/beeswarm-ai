# Waxes

**Waxes** are inventory items introduced in the 2021-12-26 Update. They are used by players to modify the stats and abilities of Beequips.

There are currently five different types of Waxes, and each wax affects a Beequip differently. Players can apply up to 5 Waxes to a single Beequip. If more waxes need to be applied, the player must first use **Turpentine** on the Beequip to remove all existing modifications, resetting the stats back to their original state.

Waxes are also utilized in crafting various items, including Planters, Tools, and higher-tier Waxes within the Blender.

## Wax Types

The following five wax types are currently available:
*   Soft Wax
*   Hard Wax
*   Caustic Wax
*   Debug Wax
*   Swirled Wax

## Use in Quests

Waxes are required for several quests associated with different characters:

### Dapper Bear
*   **A Good Infection (#3):** Requires collecting 10 Soft Waxes.
*   **All About Appearances (#4):** Requires using 5 Soft Waxes and 1 Hard Wax.
*   **The Long Haul (#10):** Requires using 10 Hard Waxes.
*   **Ongoing Maintenance (#13):** Requires using 50 Soft Waxes.

### Science Bear
*   **Repairing The White Drive:** Requires obtaining 12 Soft Waxes.
*   **Corrupting The Glitched Drive:** Requires obtaining 12 Hard Waxes.

### Bee Bear
*   **Finishing The Festive Planter (#10):** Requires collecting 10 Soft Waxes.
*   **Upgrading The Honeydays (#13):** Requires using 5 Soft Waxes.
*   **Cogs For The Cub Buddy (#15):** Requires using 5 Hard Waxes.
*   **Peppermint Preparation (2/5) (#17):** Requires collecting 30 Soft Waxes.
*   **Peppermint Preparation (3/5) (#18):** Requires using 1 Swirled Wax.
*   **Peppermint Preparation (4/5) (#19):** Requires collecting 30 Hard Waxes and 5 Caustic Waxes.

### Bubble Bee Man
*   **B.B.M's Naughty List (Beesmas 2021):** Requires collecting 555 Soft Wax tokens and using 9 Caustic Waxes.
*   **B.B.M's Naughty List (Beesmas 2022):** Requires destroying 31 Beequips that have been modified with Caustic Waxes.
