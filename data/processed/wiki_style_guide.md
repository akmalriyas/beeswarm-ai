# Wiki Style and Formatting Guidelines

This guide outlines all necessary formatting standards to maintain consistency across the wiki. While memorizing every point is unnecessary for initial editing, adherence to these guidelines is required. For further assistance with formatting, refer to the [FAQ/Wiki Code] article. If issues arise, contact a staff member or review the [Editing Guidelines].

**Note:** This wiki uses American English exclusively. Do not introduce other languages onto pages. To read content in another language, use an external translator or visit a different language version of the wiki.

## Content Standards

*   **Game State Accuracy:** Articles must reflect the current state of the game. Rumors and future content are strictly prohibited, even if sourced from developers (Onett).
    *   This includes content found in the Test Realm.
    *   Do not use temporal phrasing such as "since the [insert date here] update..." Instead, describe the game's current state as if it has always been that way. Historical behavior should be relegated to the Trivia section.
    *   Debug or developer gear inaccessible to standard players is not considered part of the current game state.
*   **Removed Content Template Usage:** The `Removed Content` template must only be applied to items that have been permanently removed from the game. Items that are no longer obtainable, but still exist (e.g., a first-edition Tabby Bee), should not use this template. Use specific templates, such as `Unobtainable`, when appropriate.
*   **Objectivity:** Articles must remain objective; opinionated statements are prohibited. Value judgments ("this is a good thing") or superlatives ("greatest") indicate an opinion and belong in blog posts, not articles. Phrasing like "oddly enough" may also carry undue weight as an opinion.
*   **Page Creation:** Unless there has been a recent update, do not create new pages. If a page cannot be found, assume the fault lies with the editor until proven otherwise. Use the Discussions page if necessary.
    *   If a page is found to be incorrect (unrelated, duplicate, or fanon), notify a staff member or edit the page and place the special code `{{Delete}}` at the top.
    *   Traveling Bears who have departed are subject to the `Removed Content` template, regardless of promises to return.
*   **Trivia:** Trivia must be noteworthy and not extremely obvious. Avoid adding redundant information (e.g., stating an item is the most expensive when it is already established as such). When comparing items in trivia, ensure a direct, relevant connection exists between them.
*   **File Efficiency:** Items sharing the same image file (e.g., Nectar Tester using the Basic Egg icon) must all link to that single file. Duplicate files should be avoided.
*   **Sourcing:** Any information added that cannot be verified or was not previously found in the game requires a reference with a direct source link.

## Categories

*   Categories are used solely to categorize the subject of the **entire** article. An article discussing removed items will only be categorized as "Removed Content" if *every* item within it is removed.
    *   An exception exists if the page serves as the sole documentation for a specific subject (e.g., a dedicated Chick article).
*   New, unused categories should only be created if absolutely necessary.
    *   Users are permitted to use any category that is not used in mainspace articles within user pages and blog posts.
*   Unhidden categories should generally be capitalized like a title.

## Grammar and Mechanics

In general, all writing must adhere to correct spelling and grammatical standards.

*   **Grammar:** Pay close attention to subject-verb agreement, homonyms, and basic rules. For specific items (like field dice), pluralization may not always apply; phrases such as "1 field dice" or "1 jelly beans" are permitted but should be avoided unless listing obtainment methods.
*   **Galleries:** Galleries must follow all the rules stated in this section, with the exception that full sentences are not required to explain an image.
*   **Quoting Errors:** If quoting Onett's spelling error verbatim (e.g., in quest dialogue), mark the error using `_[sic]_`. For other errors, silently correct them and note the correction in the page's Trivia section.

## Capitalization Rules

Use proper capitalization for all proper nouns and adjectives.

**Proper Nouns Include:**
*   Named locations and time frames (e.g., Dapper Bear's Shop, Red Brick Field, Beesmas Summer 2024 Event).
*   Specific bees and bears (including Snowbear).
*   Bosses, mini-bosses, and specific aphids (including modifications; e.g., "First Edition Gifted Mutated Bear Bee").
*   Named items (e.g., Hydroponic Planter, Compressor, Electro-Magnet).
*   Abilities (e.g., Blue Boost, Festive Mark).
*   Specifically named bee tiers (e.g., Blue Event bee, Legendary bee). Note: General colors remain lowercase when used descriptively ("blue fields").
*   Named stickers (e.g., Bear Bee Offer Sticker, Colorful Buttons Sticker).
*   Badge tiers and listed proper nouns (e.g., "Demon, Looker, and Buoyant Bees" — the word "Bees" is part of the name).

**Common Nouns Include:**
*   Generic terms/categories (e.g., item, planter, machine).
*   Mobs.
*   Generic items (e.g., strawberries, swirled wax). This includes made-up names like neonberries and beequips, and the generic term "sticker."

**Exceptions:**
*   Infoicon templates (like `Template:Cost` or `Template:Color`) maintain their default capitalization.
*   Verbatim text copied from Onett (including descriptions) is exempt.

## Pronoun Usage

*   **Voice Consistency:** Maintain a consistent, third-person voice. "The player" is preferred over "you." Alternative forms include the imperative ("Step on the pad to purchase...") or passive voice ("Stepping on the pad purchases...").
    *   While not mandatory, the second person view ("you") may be appropriate in specific contexts, such as Tip sections, prioritizing readability over strict formality.
    *   The singular "they" is acceptable if it aids conciseness and readability.
*   **First Person:** The first-person voice must never be used.
*   **Pronoun Assignment:**
    *   All bears are male ("he"), unless specified otherwise (Mother Bear and Spirit Bear are female). Robo Bear is inanimate ("it").
    *   Mobs are generally referred to as "it," except for the Werewolf and King Beetle, who can be "he."
    *   Bees are neutral ("it" or "they") despite being biologically female. Specific bees referenced in dialogue are exceptions.
*   **Naming Conventions:** Bee and bear names are treated as proper nouns; they should not be referred to generically (e.g., avoid "the Rad Bee"). Mobs' names function as labels and can be referred to generally (e.g., "the ladybug"). Names treated as proper nouns require the use of "who," not "that."

## Punctuation

*   **Sentence Structure:** Avoid run-on sentences. Two independent clauses must be separated by a conjunction, semicolon, or a period. Using only commas or no punctuation between connected clauses constitutes a run-on sentence.
*   **Ending Sentences:** All sentences must end with a period. Bullet points listing phrases should also conclude with periods.

## Formatting Rules

*   **Initial Mention:** The first mention of an article's subject must be **bold**. Subsequent mentions use standard formatting. This rule extends to similar functional templates (e.g., `Template:Color`).
*   **Dates:** Write out the full date whenever possible (e.g., November 24, 2018). If space is limited, use the ISO date format: **YYYY-MM-DD**. Other formats are prohibited due to ambiguity. Avoid punctuation other than hyphens between digits.
*   **Ambiguity in References:** When referencing an article with clarifying parts (e.g., "Honey Bee (NPC)"), do not include the parenthetical qualifier unless absolutely necessary for clarity.
*   **Template Placement:** Notice templates (like `Removed Content`) must be placed at the very top of the section they reference. If the template covers the entire article, place it at the top of the page.
*   **Internal Linking:** Do not use external link syntax for internal wiki links (e.g., avoid `[[1]](https://bee-swarm-simulator.fandom.com/)`). Use the provided Visual Editor options or Source Editor conventions.
*   **Headings and Lists:** Utilize headings and subheadings correctly. Always use actual bullet lists, not asterisks or hyphens.
