# Daily Top Memory Matchers Leaderboard

The **Daily Top Memory Matchers** is one of 64 leaderboards available in Bee Swarm Simulator. It can only be viewed through the Global Leaderboards menu within the System Page.

This leaderboard tracks the total number of successful matches players have made across various Memory Matches on a given day. The board displays 10 positions at a time, but players can scroll to view up to the 100th place. The rankings reset daily at 12:00 AM CST.

## Rewards
Players who achieve specific ranks by the end of the day are awarded prizes:

*   **Top 25:** Awarded one Mythic Egg.
*   **Top 100:** Awarded 50 Tickets.
