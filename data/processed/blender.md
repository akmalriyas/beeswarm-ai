# Blender

![Betterblender](https://static.wikia.nocookie.net/bee-swarm-simulator/images/a/a4/Betterblender.png/revision/latest/scale-to-width-down/268?cb=20260218183516) The Blender

## Overview
The Blender is a machine located inside the Badge Bearer's Guild. Its primary function is to craft consumable items from pre-existing ingredients. Players can only craft one type of item at a time, and there are 20 different items available in total.

### Usage Details
*   **Location:** Badge Bearer's Guild
*   **Requirement:** Access to the Badge Bearer's Guild
*   **Cooldown:** None

## Crafting Mechanics
The Blender takes 5 minutes to craft an item. The crafting timer only counts down while the player is actively in-game, unless they possess an Offline Voucher. If an Offline Voucher is used, the blending process will continue for up to 24 hours after the player logs out.

Players can interrupt the crafting process at any time by clicking "End Crafting." This action returns all unfinished ingredients and gives the player all completed items.
*   If the button is green, the item has finished blending.
*   If the button is red, the blending process is still in progress.

### Speeding Up Blending
Players can speed up the crafting time using Tickets:
*   For standard items, 1 additional Ticket is required for every single item being crafted.
*   For Moon Charms and Gumdrops, each Ticket speeds up a batch of 10 items.

## Trivia
*   A Star Jelly token is found on the lid of the Blender. It can be obtained by repeatedly jumping on the handle with sufficient Jump Power, standing on the gate to the Ace Badge section and gliding toward the top, or performing a difficult head-hitter.
*   If an item is selected for crafting but not started ("blended"), leaving and re-opening the blender will display the required ingredients (e.g., red extracts), even if the quantity exceeds available resources; however, the player will be unable to confirm the craft.
*   During Beesmas 2022, players could use blender refunds for "collect items" quests, but this mechanic was later fixed.
*   When crafting an item requiring two or more strawberries, it may incorrectly display as `[-n Strawberrys]` instead of the correct plural spelling.
*   There is a known misspelling when using enzymes for crafting: the ingredient name appears as `[-n Enzymess]`. However, if the player crafts Enzymes themselves, the correct spelling will appear.
*   If an Offline Voucher has been redeemed, the message displayed above the buttons while crafting changes to: "You've redeemed the offline voucher! The blender will continue running for up to 24 hours while you are offline."
