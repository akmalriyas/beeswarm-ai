# Mythical Bees

| Bee | Description |
| :--- | :--- |
| **Buoyant Bee** | Just like a balloon, nothing can keep this bee down. It is always ready to party. |
| **Fuzzy Bee** | This unkempt ball of fluff is actually a bee. Its fur aids in the pollination of flowers. |
| **Precise Bee** | This sharpshooting bee is always on point and expects the same level of precision from you. |
| **Spicy Bee** | Some like it hot—this bee likes it scorching. Even the honey it produces is spicy. |
| **Tadpole Bee** | A tiny amphibious bee who dreams of growing up to become a frog. |
| **Vector Bee** | A bee brought to life by an extremely complex trigonometric equation. |
